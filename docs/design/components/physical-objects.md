# Component family — physical objects

Physical objects are high-impact vocabulary. Use them to make the workbench believable, not ubiquitous.

## Physicality budget

A page should have a broad field of low-physicality UI and a few tactile anchors. High-physicality objects work because they are rare.

- 3: PaperSheet, ProgressTrack, PaintSwatch, Plaque, Drawer, Stamp, Medallion.
- 4: Tray, Shelf, StickyNote.
- 5: Pin, Screw/StructuralHardware.

## Tray
Must group a real collection. If removing the tray changes no semantic grouping, use a panel instead.

## Shelf
Reserved for showcasing collections or achievements. It is not a generic grid wrapper.

## StickyNote
Signals temporary/personal/contextual information. Appropriate for Curator/reminders/suggestions; inappropriate for a core setting or required instruction.

## PaperSheet
Can overlap and appear liftable, but remains clean archival paper. Do not distress it.

## Pin
A pin must visibly attach a flexible object. Never place four pins at card corners as decoration.

## Screws / StructuralHardware
Used only where rigid structure plausibly joins. Brass is the default; steel is technical/utility. Pins and screws share the 0–4 recommended / 6 hard-maximum screen budget.
