# Tamiya Color Acrylic Paint

`acrylic-catalog.csv` is the Tamiya Color Acrylic Paint range (X and XF), built by
`scripts/fetch-new-line-catalogs.mjs` from tamiya.com's product lists: the 23 ml range
plus the colours sold only as 10 ml "Mini" bottles (XF-70 onwards, X-35).

Hexes are sampled from Tamiya's own colour chip images (`hex_source = manufacturer`);
swatches are crops of the same chips. Thinner, Flat Base and the clear varnishes have
no hex and don't colour-match.

Pairings to these paints come from AK Interactive's Real Colors chart
(see `../ak-interactive/`).
